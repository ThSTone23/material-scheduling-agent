# 工具使用与验证说明

开发过程中使用语言模型辅助技术资料检索和初稿整理；提交物以源码、合成规则、可执行测试和可复现运行记录为准。运行时在线决策服务与开发辅助相互独立。

实现将动作限制为 JSON 协议，并将硬性时间变更、幂等保存与“永不发布”置于本地守卫中。离线适配器支持无密钥环境下的流程验证；线上配置通过环境变量读取，不提交真实密钥。

验证通过 `unittest` 覆盖强制验收点，实际结果见 `examples/test-results.txt`；正常与冲突两条在线运行记录分别见 `examples/outputs/online_*.json` 和 `examples/traces/online_*.json`。
