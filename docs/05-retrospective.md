# 复盘

## 实际用时

约 3 小时（设计与边界 45 分钟、实现 85 分钟、测试及交付材料 50 分钟）。

## 最难的问题与收获

难点不是把工具串起来，而是区分“模型建议”和“系统授权”。如果只把冲突时段替换为可用时段后直接保存，就会违反硬性发布时间要求。因此替代时段仅作为建议，必须显式确认。另一个容易遗漏的点是保存返回值：调用成功不代表保存成功，故 Agent 会读取 `save_draft` 的结果后再决定最终状态。
